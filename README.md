# 🥊 Fighters Arena

#### Интерактивный Telegram-бот для проведения боев двух персонажей с использованием ИИ.

## 🚀 Ключевые особенности (Features)

* 🧠 **Генерация боев на лету** за счет использования Groq API.
* ⚔️ **Возможность сразиться со своим другом** любым персонажем.
* 📱 **Грамотно построенный UI и UX.**
* ✨ **Хорошо оформленный ответ.**

---

## 🎮 Игровая механика (Game Mechanics) 

* 🌐 Возможность играть в онлайне с помощью команды `/search`
* 🤖 Возможность игры с ботом, если не получается найти противника, командой `/start`
* 🔮 Отсутствие галлюцинаций даже несмотря на продолжительность боя  

🏁 **Старт:** У игрока 100 HP, также он прописывает свою силу и имя своего героя, и система запрашивает дальнейшие действия игрока в сражении. После этого идет цепочка действий, которые прописывают игроки. Эта цепь длится до того момента, пока у кого-либо из игроков значение HP станет равным нулю либо меньше.

---

## 🛠️ Технический стек (Tech Stack)

* **Язык:** `Python` 🐍
* **Бот-фреймворк:** `pyTelegramBotAPI` 🤖
* **База данных:** `SQLite` 📦
* **ИИ-модель:** `GPT` через API Groq 🧠

---

## 📂 Структура проекта (Project Structure)

* 📄 **`main.py`:** Логика общения с ИИ и расчет игровых параметров.
* 📄 **`tgbot.py`:** Обработка команд Telegram и интерфейс пользователя.

---

## ⚙️ Установка и Запуск (Installation)

1.  📥 **Клонируйте репозиторий.**
2.  📦 **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```
3.  🔑 **Добавьте свой API Key и Bot Token в файлы.**
4.  ▶️ **Запустите команду:**
    ```bash
    python tgbot.py
    ```

## 💾 Схема базы данных (Database Schema) 
**messages**

| Поле | Тип | Описание |
| :--- | :---: | ---: |
| id | INTEGER | Индексация для каждого сообщения |
| user_ID | INTEGER | Индексация игровой сессии |
| role | TEXT | Отправитель |
| character_name | TEXT | Имя персонажа |
| p1 | INTEGER | Индификатор 1 игрока |
| p2 | INTEGER | Индификатор 2 игрока |
| HP | INTEGER | Значение параметра "жизнь" |
| POWER | INTEGER | Значение параметра "сила" |
| CONTEXT | TEXT | Контекст |

**queue**

| Поле | Тип | Описание |
| :--- | :---: | ---: |
| user_ID | INTEGER | Индификатор игрока |

**session**
| Поле | Тип | Описание |
| :--- | :---: | ---: |
| session_id | INTEGER | Индексация игровой сессии |
| playerid_1 | TEXT | Имя игрока 1 |
| playerid_2 | TEXT | Имя игрока 2 |
| p1 | INTEGER | Индификатор 1 игрока |
| p2 | INTEGER | Индификатор 2 игрока |
| p1_context | TEXT | Сообщения игрока 1 |
| p2_context | TEXT | Сообщения игрока 2 |
